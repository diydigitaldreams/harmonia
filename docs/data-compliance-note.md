# Data Compliance Note

Harmonia uses a synthetic English-language developer-support dataset for this proof-of-concept.

No real user conversations, social media posts, Discord logs, client data, confidential company data, personal information, or PII are included in this repository.

## Dataset Source

The sample messages are manually written synthetic examples. They model common developer-support situations such as:

- setup confusion
- inconsistent documentation
- unclear environment variable names
- repeated onboarding questions
- vague error messages
- missing validation guidance

## Excluded Data

This project must not include:

- real Discord, Slack, forum, or social media exports
- client support tickets
- confidential internal bug reports
- usernames tied to real people
- email addresses
- phone numbers
- credentials
- API keys
- secrets

## Submission Review

Before final submission, all repository files and Bob session exports should be reviewed to confirm that no sensitive information is present.
