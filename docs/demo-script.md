# Demo Script Draft

Target length: under 5 minutes.

## Opening

Harmonia is a proof-of-concept for turning messy developer-support chatter into repo-aware engineering action with IBM Bob IDE.

The problem is simple: teams often hear about bugs, setup problems, and documentation gaps in chat long before those problems become clean engineering tickets. Harmonia closes that gap.

## Demo Flow

1. Load synthetic developer-support chatter.
2. Show detected issue clusters.
3. Review severity, category, confidence, and review status.
4. Open the generated IBM Bob IDE task prompt.
5. Show the engineering-ready ticket.
6. Show acceptance criteria, test plan, and documentation update plan.
7. Point to the `bob_sessions/` folder with exported Bob reports.

## Key Line

Harmonia does not replace engineers. It helps teams move from noisy signal to useful action faster, with IBM Bob IDE as the primary development partner.

## Bob Usage Callout

IBM Bob IDE was used to plan, implement, review, document, and prepare this proof-of-concept. Relevant task session reports are included in `bob_sessions/`.

## Compliance Callout

The demo uses synthetic English-language developer-support data only. No real Discord logs, client data, confidential information, personal information, or API keys are included.

## Closing

Harmonia helps teams turn idea into impact faster by converting support noise into structured, repo-aware software work.
