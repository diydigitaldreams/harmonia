# Judging Map

This document maps Harmonia to the expected hackathon evaluation areas.

## Theme: Turn Idea Into Impact Faster

Harmonia speeds up the transition from scattered human feedback to actionable software work.

Instead of leaving bugs, setup friction, and documentation gaps buried in chat, Harmonia structures those signals into tickets, Bob prompts, tests, and documentation tasks.

## Application of Technology

Harmonia is designed around IBM Bob IDE as the primary AI development partner.

Bob is used for:

- MVP planning
- repo-aware implementation support
- code review and refinement
- documentation generation
- demo preparation
- exported task session reports

The app also generates Bob-ready prompts so future issue clusters can be handed to Bob for repo-aware analysis and implementation.

## Business Value

Engineering teams lose time translating vague human reports into clear work.

Harmonia reduces that friction by producing:

- issue clusters
- confidence scores
- review routing
- engineering tickets
- acceptance criteria
- test plans
- documentation update suggestions

This is useful for hackathon teams, developer tools companies, support-heavy SaaS teams, and internal engineering organizations.

## Originality

Harmonia is not just sentiment analysis and not just a chatbot.

It is a signal-to-software workflow: chatter becomes structured engineering action.

## Presentation

The demo should show a simple before-and-after:

Before: messy synthetic developer-support messages.

After: a clear issue cluster, Bob IDE task prompt, engineering ticket, acceptance criteria, test plan, and documentation plan.

## Compliance

Harmonia uses synthetic English-language developer-support data only.

The repository should contain only safe public hackathon materials and should be reviewed before submission.

## Required Submission Artifacts

Planned artifacts:

- public GitHub repository
- README
- working proof-of-concept
- written statement
- video pitch under 5 minutes
- exported Bob IDE session reports in `bob_sessions/`
